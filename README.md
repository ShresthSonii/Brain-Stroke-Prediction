# 🧠 Brain Stroke Risk Prediction System

An end-to-end Machine Learning solution and interactive Flask web application designed to assess brain stroke risk based on clinical parameters and patient health metrics.

---

## 📌 Project Overview
Stroke is a leading cause of severe disability and mortality globally. Early detection of risk factors significantly improves preventative care outcomes. This project builds a supervised machine learning model trained on patient demographic and physiological data (e.g., age, hypertension, heart disease, average glucose level, BMI) to predict stroke likelihood.

---

## 🏗️ Architecture & Features

- **Machine Learning Pipeline:** Data preprocessing, handling class imbalance (SMOTE), feature scaling, and model training.
- **Model Evaluation:** Detailed performance tracking using ROC-AUC curves, Precision-Recall curves, and Confusion Matrices.
- **Interactive Web Portal:** Flask-backed web server for single-patient clinical risk assessment.
